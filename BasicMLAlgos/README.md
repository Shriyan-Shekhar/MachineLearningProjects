# Basic ML algos
1. Linear Regression - Supervised - Predicting a continuous target variable based on one or more predictor variables.
2. Logistic Regression - Supervised - Binary classification problems; predicts the probability of a binary outcome.
3. Decision Tree -  Supervised -  Classification and regression tasks; models decisions based on feature values.
4. Support Vector Machines (SVM) - Supervised -  Classification tasks; finds the hyperplane that best separates different classes.
5. Naive Bayes - Supervised - Classification; based on Bayes' theorem, it assumes independence between features.
6. Gradient Boosting Machines - Supervised - An ensemble technique that builds models in a sequential manner, correcting errors of previous models.
7. Principal Component Analysis (PCA) - Unsupervised - Dimensionality reduction; transforms data to a lower-dimensional space while retaining variance.
8. Random Forest - Supervised - An ensemble method that combines multiple decision trees to improve accuracy and control overfitting.
9. K-means Clustering - Unsupervised -  Clustering; partitions data into 'k' distinct clusters based on feature similarity.
